## Динамическая покраска моделей ($color2)

**Динамическая покраска** — это технология движка [[Source Engine 1|Source]], позволяющая изменять цветовой тон материала модели в реальном времени без перезагрузки текстур из памяти.

Ключевые особенности механики

- **Принцип работы:** Пиксельный [[Шейдеры|шейдер]] `VertexLitGeneric` выполняет операцию попиксельного умножения (Multiply) исходного цвета диффузной текстуры ([[$basetexture]]) на RGB-вектор, переданный из игры.
- **Применение в Garry's Mod:** Это фундаментальный стандарт для систем кастомизации. Он используется для изменения цвета кузовов автомобилей (через контекстное меню / Color Tool), покраски элементов одежды игрока (Playermodels), динамического изменения цвета команд в режимах (например, в _Trouble in Terrorist Town_ или _DarkRP_), а также для визуализации эффектов урона (покраснение при ранении).

## 📐 Архитектура и синтаксис в VMT

В старых версиях движка Valve использовала параметр `$color`. В современной ветке Garry's Mod стандартом является параметр **`$color2`**.

- **Почему `$color2`:** Старый параметр `$color` аппаратно перезаписывал данные повершинного освещения (Vertex Lighting) и ломал отрисовку статических теней. Параметр `$color2` умножает цвет текстуры _после_ расчета освещения, сохраняя глубокие тени и блики нетронутыми.

Базовый синтаксис VMT (Тотальная покраска):

```vmt
"VertexLitGeneric"
{
	"$basetexture" "models/props/car_paint"
	"$bumpmap"     "models/props/car_paint_normal"
	
	// Вектор цвета по умолчанию [R G B] от 0.0 до 1.0 (Белый = без изменений)
	"$color2"      "[1.0 1.0 1.0]" 
}
```

Используйте код с осторожностью.

## 📦 Продвинутый метод: Выборочная покраска по маске (`$blendtintbybasealpha`)

Если применить `$color2` к модели человека, то при попытке перекрасить его куртку в зеленый цвет, его лицо, волосы и обувь также станут зелеными. Для изоляции зон покраски используется параметр **`$blendtintbybasealpha`** (смешивание оттенка по альфа-каналу базовой текстуры).

Пайплайн упаковки каналов:

1. **RGB-каналы `$basetexture`:** Вся модель красится в свои стандартные цвета (лицо — телесный, джинсы — синие). Но зона, которая должна краситься (например, куртка), обязательно переводится в **строго черно-белый (серый) градиент**. Если куртка останется цветной, при наложении краски цвета смешаются некорректно.
2. **Альфа-канал `$basetexture`:** Выступает в роли маски покраски (Tint Mask).
    - **Белый цвет (`255`):** Зона на 100% восприимчива к динамическому цвету `$color2` (куртка).
    - **Чёрный цвет (`0`):** Зона полностью игнорирует `$color2` и сохраняет свои исходные цвета из RGB (лицо, джинсы).

Настройка VMT для выборочной покраски:

```vmt
"VertexLitGeneric"
{
	"$basetexture"           "models/player/swat_soldier" // Альфа хранит маску покраски!
	"$bumpmap"               "models/player/swat_soldier_normal"
	
	// Активация покраски по альфа-маске
	"$blendtintbybasealpha"   "1" 
	"$blendtintcoloroverbase" "0" // 0 - мягкое умножение, 1 - жесткое перекрытие цвета
	
	"$color2"                "[1.0 1.0 1.0]"
}
```

Используйте код с осторожностью.

## 💻 Интеграция с Lua в Garry's Mod

Garry's Mod предоставляет прямой доступ к изменению вектора цвета энтити через Lua-API. Движок автоматически транслирует это значение в параметр `$color2` соответствующего материала.

1. Покраска через стандартный API объекта (Для игроков и пропсов):

Если материал модели подготовлен (как указано выше), Lua-скрипт может перекрасить объект одной строкой:

```lua
// Серверный или клиентский скрипт
local ent = ... // Ссылка на проп или игрока
-- Перекрашиваем объект в ярко-красный цвет (RGB: 255, 0, 0)
ent:SetColor( Color(255, 0, 0, 255) )
```

Используйте код с осторожностью.

2. Прямая манипуляция параметром VMT через `IMaterial`:

Если вам нужно перекрасить конкретный материал на модели, не затрагивая остальные, используется прокси-доступ к шейдеру:

```lua
if CLIENT then
    -- Находим нужный материал в кэше движка
    local mat = Material("models/player/swat_soldier")
    
    -- Переводим цвета из формата 0-255 в формат векторов Source (0.0 - 1.0)
    local red = 0.0
    local green = 1.0
    local blue = 0.0
    
    -- Принудительно перезаписываем вектор $color2 на лету (сделает куртку зеленой)
    mat:SetVector("$color2", Vector(red, green, blue))
end
```

Используйте код с осторожностью.

## 🛑 Известные баги и технические ограничения

- **Эффект «Грязного наложения» (Цветовой шум):**
    - _Причина:_ Попытка динамически покрасить базовую текстуру, у которой зона покраски в RGB-каналах не была предварительно обесцвечена (осталась цветной). Например, если исходная куртка была желтой, а Lua передает синий цвет `$color2`, то по законам умножения пикселей (`Желтый * Синий`) куртка в игре станет ядовито-зеленой или грязно-коричневой.
    - _Решение:_ Всегда переводить красящиеся зоны в оттенки серого на текстуре альбедо.
- **Потеря Phong-блика при сильном затемнении цвета:**
    - _Причина:_ Так как Блинн-Фонг блик ([[$phong]]) математически зависит от базовой яркости пикселя в некоторых старых шейдерных конфигурациях, передача в `$color2` черного цвета `[0.0 0.0 0.0]` может полностью «затушить» отражения света, сделав модель абсолютно матовой и плоской.
    - _Решение:_ Не использовать абсолютно черный цвет. Для черных материалов передавайте в Lua значения `Vector(0.1, 0.1, 0.1)`, регулируя яркость самого блика через `$phongboost`.
- **Конфликт с прозрачностью (`$translucent`):**
    - _Причина:_ Альфа-канал базовой текстуры может выполнять только одну функцию. Если вы включили `$blendtintbybasealpha "1"`, альфа-канал уже занят маской покраски. Использовать его для прозрачности стекла или дыр (`$translucent "1"`) больше нельзя.
    - _Решение:_ Переносить маску прозрачности в альфа-канал карты деталей ([[$detail]]) или использовать бинарную прозрачность `$alphatest`, жестко настраивая приоритеты слоев.
