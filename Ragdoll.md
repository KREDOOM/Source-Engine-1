## Ragdoll (Физика тряпичной куклы)

**Ragdoll (Рэгдолл)** — это специализированный режим работы модели в движке [[Source Engine 1|Source]], при котором скелетная анимация полностью отключается, а управление костями передается физическому поддвижку **VPhysics** (модифицированному _Havok_). Он симулирует физику обмякшего тела (трупа) с учетом массы, инерции, гравитации и анатомических ограничений суставов.

Ключевые особенности механики

- **Принцип работы:** Движок не рассчитывает физику для каждого полигона модели персонажа — это сожгло бы ресурсы процессора. Вместо этого физический движок просчитывает поведение **физбокса** (`$collisionjoints`) — упрощенного скелета из жестких геометрических коробок и капсул. Визуальная высокополигональная сетка модели (`.mdl` / `.vvd`) просто «натягивается» поверх этих движущихся коробок в реальном времени.
- **Применение в Garry's Mod:** Рэгдоллы являются визитной карточкой GMod. Они используются для создания физических тел умерших NPC и игроков (Playermodels), работы инструмента _Physics Gun_ (физган), позинга в песочнице и создания реалистичных анимаций смерти в кастомных режимах (например, TTT или DarkRP).
- **Где хранятся данные:** Все физические параметры, развесовка, лимиты суставов и хитбоксы компилируются в бинарный файл физических данных **`.phy`**.

## 📐 Архитектура и синтаксис в файле компиляции (.QC)

Сборка рэгдолла кардинально отличается от сборки статичного пропса. Вместо команды `$collisionmodel` используется продвинутый блок **`$collisionjoints`**. Каждая физическая кость прописывается отдельно с жестким указанием лимитов вращения в градусах по трем осям (X, Y, Z).

Базовый синтаксис блока `$collisionjoints`:

qc

```
$collisionjoints "имя_физического_меша.smd"
{
	$mass 85.0                            // Общая масса тела в килограммах
	$inertia 10.0                         // Множитель общей инерции объекта
	$damping 0.01                         // Затухание линейного движения (сопротивление воздуха)
	$rotdamping 1.5                       // Затухание вращения (трение в суставах)

	// Настройка конкретного сустава (например, колена или локтя)
	"имя_кости_в_скелете"
	{
		$mass 5.0                         // Локальная масса этой части тела
		$inertia 1.0
		$damping 0.01
		$rotdamping 1.5
		
		// Лимиты вращения в градусах [Минимум Максимум Затухание]
		$rootbackwardscompat "ValveBiped.Bip01_Pelvis" // Совместимость с родительской костью
		$limitaxis X min -30 max 30 friction 1.0
		$limitaxis Y min -10 max 10 friction 1.0
		$limitaxis Z min -45 max 90 friction 1.0
	}
}
```

Используйте код с осторожностью.

## 🛠️ Практический пример: Компиляция физического скелета гуманоида

Ниже приведен фрагмент реального `.qc` файла для настройки базовых суставов (таза и бедра) человекоподобного персонажа на стандартном скелете ValveBiped.

qc

```
$modelname "player/custom_ragdoll.mdl"
$body "body" "soldier_reference.smd"
$cdmaterials "models/player/custom_soldier/"

// Ссылка на анимацию смерти или позу, из которой рэгдолл стартует
$sequence "ragdoll" "soldier_reference.smd" activity "ACT_DIERAGDOLL" 1 frames 0 0

// Настройка физического скелета
$collisionjoints "soldier_physics.smd"
{
	$mass 80.0
	$inertia 10.0
	$damping 0.01
	$rotdamping 1.5
	$rootbone "ValveBiped.Bip01_Pelvis" // Главная корневая кость (таз)

	// Настройка сустава таза (Pelvis)
	"ValveBiped.Bip01_Pelvis"
	{
		$mass 20.0
		$damping 0.0
		$rotdamping 0.0
	}

	// Настройка левого бедра (Сустав сгибания ноги)
	"ValveBiped.Bip01_L_Thigh"
	{
		$mass 10.0
		$inertia 1.0
		$damping 0.02
		$rotdamping 1.0
		
		// Нога может сильно гнуться вперед, слабо назад и немного вбок
		$limitaxis X min -20 max 40 friction 1.0
		$limitaxis Y min -30 max 30 friction 1.0
		$limitaxis Z min -80 max 20 friction 1.0
	}
	
	// Далее последовательно прописываются все остальные кости: голени, плечи, голова...
}
```

Используйте код с осторожностью.

## 🛑 Известные баги, лимиты и технические ограничения

- **Баг «Спагетти» (Адское растягивание меша):**
    - _Причина:_ Самый частый баг кастомных рэгдоллов в Garry's Mod. Возникает, если физический меш коллизии (`soldier_physics.smd`) содержит коробки для костей, которые не прописаны в блоке `$collisionjoints`, либо нарушена иерархия родительских связей костей. При спавне физбокс падает на пол, а визуальный меш растягивается в длинные резиновые ленты к нулевым координатам карты.
    - _Решение:_ Перепроверить, чтобы каждая геометрическая коробка в физическом `.smd` была жестко привязана ровно к одной кости, и все эти кости были перечислены в QC.
- **Баг «Бешеной судороги» (Рэгдолл бьется об стены и летит в космос):**
    - _Причина:_ Взаимное пересечение физических коробок физбокса. Если коробка бедра физически пересекается и заходит внутрь коробки таза, движок Havok попытается силой вытолкнуть их друг из друга. Возникает бесконечный цикл микроударов, рэгдолл начинает бешено трястись, издавать пулеметный стук костей об пол и в итоге вылетает за пределы карты со сверхзвуковой скоростью.
    - _Решение:_ В 3D-редакторе Blender делайте физические капсулы суставов слегка отдаленными друг от друга. Между ними всегда должен быть микроскопический зазор в 1-2 миллиметра.
- **Лимит на количество физических костей (Bone Limit):**
    - _Причина:_ Движок Source 1 имеет жесткое ограничение: **не более 32 физических костей** в блоке `$collisionjoints`. Попытка сделать физическими все пальцы рук, уши и элементы брони приведет к ошибке компиляции.
    - _Решение:_ Объединяйте мелкие кости. Пальцы рук на физбоксе всегда объединяются в одну общую физическую варежку, привязанную к кости кисти (`Bip01_L_Hand`).

## 📦 Оптимизация и хитбоксы (`$vcollide`)

Помимо физического поведения тела, кости рэгдолла автоматически используются движком для генерации **хитбоксов** (`$bbox` / `$hbox`).

- По ним сервер рассчитывает регистрацию попаданий пуль (урон в голову, руку или ногу).
- При компиляции рэгдолла Source автоматически упаковывает данные столкновений в контейнер `$vcollide`. Если ваша модель слишком детализирована, используйте команду `noselfcollisions` внутри блоков суставов — это отключит просчет столкновений костей модели между собой (например, левая рука перестанет биться о левое бедро), что сбережет кучу серверного процессора в мультиплеере Garry's Mod.
